소개 자료를 읽고 요약하는 것과 그 설명대로 프로그램을 만들어 실행해 보는 것은 다른 작업. 후자를 거치면
어떤 설명이 구현 가능할 만큼 구체적이고 어떤 설명이 홍보 문구에 가까운지가 드러남. 이 차이의 발견이

사업 개요
한 사람의 글·강연·팟캐스트·인터뷰를 학습해 디지털 마인드(Digital Mind)를 생성하고, 그 사람
대신 24시간 응답하게 하는 플랫폼.

판매 대상               지식을 파는 사람 — 코치, 교수, 창업자, 투자자, 강연자. 자기                            창작자
                    콘텐츠를 연결해 디지털 마인드를 생성

이용 대상               링크를 열어 문자·음성 통화·영상 통화로 그 마인드와 대화하는 청중                       외부 사용자

수익 구조               창작자 대상 요금제 — Free / Builder / Scaler / Immortal. API               구독
                    접근은 Immortal 등급


출발점과 현황
창업자 Dara Ladjevardian이 작고한 조부의 책으로 대화 가능한 디지털 버전을 제작한 경험이 회사의 출발점.
현재 Karamo Brown(웰니스 코칭), Matthew Hussey, Eckhart Tolle, NBA 선수 Moses Moody 등의
디지털 마인드가 운영 중. 2025년 Sequoia Capital로부터 1,600만 달러 시리즈 A 유치.
공개된 이용 방식은 텍스트 대화, 음성 통화, 실시간 영상 통화의 세 채널. 대화 기록이 유지되어 이전 대화
내용의 참조가 가능하다는 점도 공식 문서에 기재.

기술력의 소재
공개 범위에 한정한 판단.

    판단
    차별점은 더 똑똑한 모델이 아니라,
    말을 지어내지 않게 만드는 통제 장치의 제품화.

판단의 근거
실존 인물을 대신해 말하는 서비스의 최대 위험은 성능이 아니라 그 사람이 하지 않은 말의 발화. Delphi는 이
문제를 근거 강도 3단계, 무응답 안내문, 강제 지시, 출처 표시, 민감 주제의 전문가 연결이라는 창작자가 직접
조작하는 스위치로 전환.
실제 웰니스 고객 배포 사례(Karamo Brown)에도 응답 경계·콘텐츠 검수·전문가 연결이 함께 공개되어,
문서상의 기능이 아닌 운영 중 기능임이 확인됨.

반대편 — 외부 의존과 비공개
    기반 모델·음성·영상은 외부 의존 사용자가 가장 놀라워하는 얼굴과 목소리는 ElevenLabs·Tavus 기술의 통합 결과

    독립 검증 자료의 한계 Fast Company 취재는 제품을 확인하는 동시에 반복 표현과 오래된 자료로 인한 부정확
    응답도 함께 보고

입력                  창작자 자료 · 말투 규칙 · 안전 규칙 · 대화 기록 · 사용자 질문                      JSON

복제 가능 판정의 근거
구현에는 “잘 되는 경우”만으로 불충분. 실패 시 처리의 확정이 계약 성립의 조건. Delphi는 해당 부분을 공식
문서에 기재.
    근거 확보 실패 시 창작 없이 사전 지정 안내문 출력 (Message on No Answer)
    민감·위험 질문 시 진단 없이 전문가·응급 기관 안내 (Custom Instructions · Karamo Brown 배포)
    정상 응답 시 근거 자료의 출처 부착 (공식 문서 · Fast Company 교차 확인)


실행 결과

전달해 정상 JSON 반환도 확인.

3.3 ② Delphi Actions — 복제 불가
“조용한 사용자에게 이틀 뒤 팔로업 발송” 같은 평범한 문장을 그대로 자동화 규칙으로 변환·실행하는 기능.

공개 부품 목록                                 비공개 변환 규칙
방아쇠 종류 — 키워드·문맥 알림, 대화 종료, 비활성, 결제,      자연어 지시 → 규칙 변환 스키마. 애매·불완전 지시의 처리
일정. 실행 종류 — 메시지 발송, 태그 부여, 속성 변경, 외부     방식. 규칙 충돌, 낮은 확신도, 승인 대기 상태의 전이.
시스템 호출. 즉시 실행 또는 창작자 승인 후 실행의 선택.
계약 완성에 추정에 의한 빈칸 채움이 필요하며, 그 시점에 결과물은 Delphi의 복제가 아닌 창작으로 전환.
트리거·액션 조합의 수동 축소판은 제작 가능하나 전체 워크플로는 복제 불가로 판정, 미구현.

3.4 ③ Delphi Interviewer — 복제 가능 · 미실행
AI가 창작자에게 질문하고, 답변을 근거로 새 주제와 짧은 요약을 생성해 학습 자료로 저장하는 기능. 작성할
콘텐츠가 없는 창작자의 초기 학습 자료 확보 경로.
    공개된 전 과정 질문 제시 → 타이핑 또는 음성 답변 → 후속 주제 생성 → 통찰 요약 → 편집 가능한 조각으로 저장
    공개된 경계 조건 “모르겠다” 등 짧은 답변은 진행률 미반영, 중도 이탈 시 진행분 보존
    비공개 항목 진행률 계산식, 후속 질문 선택 방식, 요약 형식
  구현 경로 MIT 라이선스 오픈소스 인터뷰 도구로 확보
동작 재현은 가능하되 내부 점수 방식은 복제 범위 밖. 이번 실행에서는 대표성이 높은 대화 기능을 우선해 빌드
대상에서 제외.

B. 층별 상세 근거
본문 2.2에서 축약한 네 개 층의 원 근거와 공개 문구.

L1 · 기억의 정리           자체 · 비공개
창작자의 자료를 축적이 아닌 개념 간 관계로 연결하고, 발언 시점이라는 시간 정보를 부착해 정리. 회사
표현으로는 “self-updating Digital Mind”, “adaptive temporal knowledge graph”. 새 콘텐츠 유입 시
자동 갱신.
근거 — Series A 공개 기술 블로그, Fast Company 취재 / 내부 구조·알고리즘 비공개


L2 · 근거의 검색           자체 · 비공개
질문 유입 시 정리된 자료에서 답변의 근거가 될 대목을 회수. 회사 설명으로는 지식 그래프를 감싼 서버리스 AI
검색 엔진과 다수 에이전트가 분담하는 분산 에이전트 메시가 담당. 목표는 “single-shot, high-precision
retrieval” — 반복 탐색 없는 단발 정확 회수. 실시간 음성·영상 대화 제품이므로 속도가 곧 제품 품질.
근거 — Series A 공개 기술 블로그 / 검색 기준값·모델 선택 비공개


L3 · 답변 생성과 통제             문서 공개
회수된 근거로 답변을 작성하되 창작자가 사전 설정한 규칙을 적용. 도움말 문서에 항목 단위로 공개된 유일한
층이며, 본 보고서의 복제가 성립한 근거.
근거 — 공식 도움말 Mind Settings, Creativity, Message on No Answer, Custom Instructions


L4 · 음성·영상 전달            외부 기술
완성된 답변을 텍스트 발송, 복제된 목소리로 낭독, 또는 실시간 영상 통화로 전달. 목소리 복제는 ElevenLabs,
실시간 영상 아바타는 Tavus의 기술을 사용. 사용자가 가장 놀라워하는 “얼굴과 목소리”는 자체 기술이 아닌
조합·통합의 결과.
근거 — Tavus 고객 사례, Businesswire 보도자료, 공식 Voice 도움말
