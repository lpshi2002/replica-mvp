# AI 테스터 행동 이력 전송 최적화

2026-10-12. 사용자가 토론 결론에 따른 수정을 요청해, 첫 단계인 O3를 파이프라인에 적용했다.
[토론 결론](../context/tasks/tester-cost-optimization-1be6cda7/conclusion.md)은 당시의 구현 전 판단으로 보존한다.

## 적용 내용

`src/replica_mvp/web_demo.py`의 `_tester_prompt`가 원본 이력을 직접 보내는 대신,
`_tester_history`로 만든 전송용 표현을 사용한다.

- 최근 15개 행동의 개수·순서·번호를 유지한다.
- 오류가 없고 `done`·`give_up`이 아닌 행동의 이유가 160자를 넘으면,
  앞부분과 `…[truncated]` 표시를 합해 160자로 줄인다.
- 행동 이력에서 값이 `null`인 필드만 생략한다. 입력란을 지우는 `value: ""`는 유지한다.
- 테스터 요청 JSON의 구분자 공백을 제거한다. 문자열 내부의 공백·줄바꿈은 유지한다.
- 긴 실제 입력값, 요소 정보, 오류와 종료 이유, 현재 화면·사례·사실·파일 목록·남은 예산·
  `read_result`는 자르지 않는다. 현재 화면과 입력란의 기존 관측 한도도 유지한다.

원본 이벤트, 화면 캡처, 관측 기록과 Judge 프롬프트의 작성 경로는 변경하지 않았다.
요약용 모델 호출도 추가하지 않았다. 모델 선택·행동 실행·판정 기준과 복제품 구현에는 변경이 없다.

160자는 저장된 401개 행동을 확인한 뒤 정한 초기 기준이다. 종료·오류를 제외한
379개 중 28개의 이유가 이 길이를 넘었다. claim-001·002의 일반 행동 이유는 대부분
100자 이내였고, claim-003에는 이전 결과와 다음 단계를 길게 반복하는 이유가 있었다.
160자가 모델 품질이나 비용의 최적점이라는 실험 결과는 아니다.

## 같은 기록에서 비교한 전송량

변경 직전과 직후의 프롬프트 생성 함수에 동일한 기록을 넣었다. 표는 합계이며 단위는
UTF-8 바이트다. 과거 실행의 실제 청구 내역을 다시 계산한 수치가 아니다.

| 비교 대상 | 표본 | 변경 전 | 변경 후 | 감소 |
|---|---:|---:|---:|---:|
| 반복 전달되는 행동 이력 | 401개 요청 | 888,070 | 749,244 | 15.63% |
| 현재 화면 등을 포함한 전체 테스터 프롬프트 | 323개 요청 | 2,964,517 | 2,725,379 | 8.07% |

전체 프롬프트 비교는 행동 직전 관측을 보관한 claim-001의 138개, claim-002의 185개
요청으로 한정했다. claim-003의 78개는 관측 체크포인트가 없어 이력만 비교했다.
각 사례의 입력값·화면·예산을 양쪽에서 동일하게 고정했고, 최종 화면과 행동 직전 화면이
같은 이벤트 번호를 사용하는 경우에는 행동 직전의 첫 관측을 사용했다.

따라서 **8.07%는 프롬프트 바이트 감소율이며, 토큰·비용 절감률이나 호출 감소율이 아니다.**
실제 모델을 호출하는 A/B는 수행하지 않았다. 캐시·토큰화·행동 선택의 변화까지 포함한
요금 및 품질 효과는 후속 실측이 필요하다. 캐시 위치 변경(O6)과 행동 묶음(O1)은
토론 결론대로 아직 적용하지 않았다.

## 검증

`tests/test_tester_history.py`에 회귀 테스트 5개를 추가했다.

- 한글·이모지·줄바꿈을 포함한 긴 입력, 빈 입력, 최근 15개 순서, 요소 정보 보존.
- 오류 행동과 종료 행동의 긴 이유 및 오류 내용 보존.
- 현재 화면·사실·긴 필드 읽기 결과 보존, 원본 자료의 비변경.
- 같은 기록에서 테스터 프롬프트를 생성해도 원본 이벤트와 Judge 입력의 바이트가 동일함.
- 로컬 브라우저로 입력·등록·승인을 실행해, 테스터에는 축약 이력이 전달되고
  저장 이벤트·화면 파일·Judge에는 원본 이유와 입력이 남는지 확인.

추가로 401개 저장 행동의 입력·오류·순서를 대조하고, 세 평가 폴더의 파일 해시가
측정 전후 동일한 것을 확인했다. 브라우저 테스트는 로컬 대체 CLI를 사용하므로
유료 모델 호출이 없다.

`PYTHONPATH=src python -m unittest discover -s tests`: **370개 테스트 통과**
(156.047초, 건너뛴 테스트 없음). `git diff --check`도 통과했다.
로그는 `tmp/reviews/tester-history-optimization-2026-10-12/unittest.log`에 있다.
기존 파일 해시를 대조해 이번 작업의 기존 소스 변경은 `web_demo.py`뿐임을 확인했다.
새 파일은 이 문서와 회귀 테스트이며, 측정용 임시 파일은 `tmp/reviews/`에 보관했다.
스테이징·커밋·푸시는 수행하지 않았다.
