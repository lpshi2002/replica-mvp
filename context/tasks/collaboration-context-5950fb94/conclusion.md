# 협업 맥락 전달 운영 개선 결론

2026-10-05 KST · 진행자 Codex · resolved

## 결정과 이유
공유 문서는 **빠지면 다음 사람이 다른 결정을 내리거나 같은 조사를 반복할 정보**를 남긴다. 분량 확대나 모든 항목을 채우는 템플릿 대신, 중요한 판단의 이유·근거 위치·미확인 가정과 필요한 제약을 보존한다.

- I-1: 결정·실행에 영향을 주는 제안에는 핵심 이유와 근거 위치를 붙인다. 원문은 링크하고, 반대 근거·기각 대안·재검토 조건은 해당 판단에 중요할 때만 적는다.
- I-2: 사용자 요구·제약과 확인한 원자료에 비추어 판단 기준을 밝히고 상대 제안의 근거·성립 조건을 대조한다. 같은 기준은 반복하지 않는다. 요구와 자료, 진행자 요약, 이전 의견을 호출문에서 구분한다.
- I-3: status는 쟁점별 현재 판단·핵심 이유·근거 링크를 둔다. 원문과 충돌하면 변경 시점·후속 사용자 결정·확인 근거를 추적한다. 오래된 원문이나 최신 요약을 자동 우선하지 않는다.
- I-4: 결론은 선택 이유를 포함한다. 다른 에이전트가 실행할 때 오해 시 결과가 크게 달라지는 범위·제약·완료 기준만 기존 계획/첫 진행 메시지에 짧게 재진술한다. 중요한 불일치가 없으면 기존 권한 안에서 진행한다. 별도 문서·승인 단계는 없다.
- I-5: 검토자는 제안자가 정한 쟁점에 답하는 데 그치지 않고 결정에 영향을 주는 누락을 새 ID로 제기한다. 반론 개수를 강제하지 않는다.
- I-6: brief의 사용자 직접 인용과 진행자 해석을 구분한다. 사용자 원문은 의도·권한의 근거이며 사실 주장은 필요하면 확인한다.

## 토론에서 바뀐 판단
[Codex 제안](001-codex-proposal.md)에 대해 [Claude 검토](002-claude-review.md)가 실제 호출문 반영과 새 쟁점 제기(I-5), 원문/해석 구분(I-6)의 누락을 지적했다. [Codex 수정안](003-codex-revision.md)은 사용자 원문을 무편향 사실로 볼 수 없고 자료 충돌에는 시점 확인이 필요하다고 수정했다. [Claude 재검토](004-claude-verification.md)는 이 수정과 실제 변경을 수용했다.

진행자 후속 판단:
- I-7: 검증 필요성은 수용했다. 문구와 제목을 고정하는 새 테스트는 추가하지 않았다. 변경은 가역적인 프롬프트/운영 문구이며, 기존 회귀 테스트, 실제 Claude 수신 확인, 양쪽 생성 결과 직접 점검으로 이번 범위를 확인했다. 영속 테스트 부재는 유지하며, 참조 선택이나 호출 동작을 바꿀 때 동작 검증 확대를 재검토한다.
- I-8: 호출 요청 제목도 `Coordinator's turn request`로 바꿔 출처를 표시했다.

## 한계와 재검토 조건
이미 읽은 제안의 영향을 없앨 수 없으므로 독립/블라인드 검토나 앵커링 감소 효과를 입증한 것으로 표현하지 않는다. 모델 간 합의도 사실 검증이나 사용자 승인을 대신하지 않는다. 기본 독립 검토 추가 턴, 새 메타데이터·문서, 반론 할당량은 비용·중복을 늘려 채택하지 않았다.

실제 토론에서 중요한 근거 누락, 제안자의 틀에 갇힌 검토, 형식적인 인계 복창, 스킬과 호출문 불일치가 반복되면 해당 원인을 재검토한다. 이번 변경은 토론·맥락 전달 운영을 보강한 것이며 제품 구현 자동 위임 시스템은 아니다.
