## 004 경계 해소
- 현재 관측 ID는 고유하지 않다. 새 전역 ID 도입 대신 참조가 가리키는 관측 묶음과 순서를 보존한다. 여러 관측을 같은 시점이라고 단정하지 않는다.
- 유효 치환 값이 저장된 뒤 파일 작성이 중단되면 그 값으로 작성만 마친다. 유효 값을 얻기 전 제공자 중단은 기록을 남겨 생성 단계 재개 가능. seed만으로 동일 입력을 보증하지 않는다. 검증 탈락값의 자동 재추첨과 확정 입력 재생성은 금지한다.
- 새 helper를 별도 파일로 분리하면 evaluator_version에도 포함한다.
- 20KB UTF-8 TXT/CSV는 최초 생성기 지원 범위다. 기업 앱 기능/입력 범위나 기존 기준을 축소하지 않는다.

## 검증 및 다음 행동
관련 코드·문서 읽기만 수행. 테스트/앱 실행/기업 재실행/제품 코드 변경 없음. 문서 변경을 검사하고 사용자에게 구체적인 네 구현 단위와 기각한 대안을 전달한다. 토론을 근거로 구현·배포를 자동 시작하지 않는다.
