## 004 조건 해소
- 관측 ID 참조 보존과 실행 폴더 밖 파일 제공 거부 테스트를 첫 작업 완료 기준에 명시한다.
- 003의 스키마 변경 제외는 조사 스키마에 관한 것이다. 신규 판정 응답·근거 기록의 필요한 변경은 첫 작업에 포함하며 근거 차단과 분리하지 않는다.
- 생성 규칙은 구현 전에 공개하고 실제 seed·값·파일은 구현 고정 후 평가 때 생성한다. 실제 사용 파일·생성 버전·검사 결과를 보존한다. 자료 품질 검사를 모델이 수행하면 근거도 남긴다.
- 참조 확인은 의미상 정답 확인이 아니다. 현재 Delphi 35개 판정의 정확성은 미검증이다.

## 검증
Claude의 38개 관련 테스트 통과와 실제 참조 64개 대조, 양측 코드 읽기를 기록한다. 전체 테스트·기업 실험·사용자 체험은 이번에 수행하지 않았다. 제품 코드·기존 결과·공유 방향 문서를 변경하지 않았다.
