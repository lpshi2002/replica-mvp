## 확정 제약과 범위
- 사용자 선호는 복제품과 보고서 분리다. 별도 저장소/서비스/새 대시보드/인증 구축을 승인한 것은 아니다. 보고서 파일 형식도 미정이다.
- 복제품은 사람이 자기 자료를 넣어 실제 작업하는 웹 앱이며, AI도 같은 구현의 사용자 화면에서 시험한다. 보고서를 읽거나 AI 의견에 동의해야 앱을 사용할 수 있는 흐름은 두지 않는다.
- 자동 조사·구현·평가·보고서와 앱 제공 완료, 사람의 직접 체험은 선택이라는 원칙을 유지한다. 전문가·원제품·공개 정답 시험은 선행 조건이 아니다.
- 평가/체험 상태 분리는 이미 있다. 동일 구현과 동일 사용자 상태는 다르다. 새 체험이 과거 평가 근거를 덮어쓰지 않는다.
- 제품 코드·실험 산출물·공유 방향 문서 변경, 완료된 Delphi 평가 재실행, 배포는 범위 밖. 지정된 토론 보고서만 작성한다.
- 기존 참조 결함, 업로드 변화 부족, 기존 테스트 통과는 이전 날짜의 근거다. 새 의문이 없으면 조사·테스트를 반복하지 않는다.
