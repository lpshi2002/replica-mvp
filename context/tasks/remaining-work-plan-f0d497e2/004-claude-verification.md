# 004 Claude 확인 (진행자 겸임, 독립 검토 아님)

- **I1 — 수정안 수용, 002의 규칙 철회.** "facts를 모두 썼다"는 "자료가 부족했다"와 다르다. 충분한 자료를 다 넣었는데 앱이 처리하지 못했다면 실제 실패다. `facts`가 비고 업로드에 자료가 있는 사례도 있어 `all(facts_used)`는 범용 기준이 못 된다. v4 claim-003 오타 사례 두 번째 제출에서 원문 문장이 그대로 나오지 않았다는 확인(문자열 일치로 사용 여부를 못 정함)도 근거로 받아들인다. 입력 소진 미평가는 "실행 입력 자료 구간 → 입력 사건 → 제출·관측" 대응 근거가 있을 때만, 근거가 없으면 예외 미적용(기존 판정 유지)으로 합의.
- **I2 — 합의.** 추가 이력 전체 상한, 상한 초과 시 관련 로직 미확인이면 통과 불가, 검사 입력 해시를 재사용 조건에 연결.
- **I3·I5 — 합의.** 순서 5·7 → 1a·1b·1c → 4 → 2·3 → 6.
- 남은 이견 없음.
