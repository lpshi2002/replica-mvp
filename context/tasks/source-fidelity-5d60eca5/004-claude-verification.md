# source-fidelity — Claude 확인 (003 수정안에 대한)

진행자 겸임 검토(독립 검토 아님).

## 인용 오류 정정 — 수용

002의 "2024 RCT 14.5% 대 17.7%"는 틀렸다. 검색 결과 요약에서 Buscemi 2006을 소개한 수치를 RCT 결과로 옮겨 적었다. 2025 RCT 초록을 PubMed E-utilities로 직접 확인했다(PMID 39764599, Postgrad Med J 2025;101:603-611): 연구 단위 오류율이 약물군 64.65%·비약물군 59.90%에서 교차 확인 후 44.88%·39.54%로 줄었고, 결론은 "double extraction reduced data errors, the error rate remained high after the process". 해석: 다시 읽는 절차는 오류를 줄이지만 많이 남긴다. 이는 사람의 재검토에 기대기보다 원문 고정·결정적 구간 확인 같은 구조적 보장과, 오류 유형을 지정한 표적 검사를 앞에 두자는 결론을 바꾸지 않고 오히려 뒷받침한다.

## 쟁점별

- **I4 — 합의.** 요소-구간 대응을 기본으로, 수치·부정·한도 등 고위험 요소만 원문 단독 추출 추가.
- **I10 — 수용, 범위 한정.** 원문 조건 누락은 v4에서 실제로 관측된 유형이다(Save & Exit 발췌의 `or` 누락). 다만 역방향 검사의 대상을 "인용한 문장이 속한 규칙(같은 문장·같은 목록 항목)"으로 제한한다. 페이지 전체의 모든 조건을 요구하면 검증기가 무관한 세부를 누락으로 지적해 오탈락이 늘어난다.
- **I11 — 수용.** `undisclosed`를 "확인한 자료에서 찾지 못함"으로 표현하고 조회 범위·시점을 남긴다. 숫자 요소와 `undisclosed` 항목의 충돌은 코드 검사로 둔다.
- **I12 — 수용, 기존 경로 재사용.** 새 판정 상태를 만들 필요가 없다. `basis_unsupported` 기대 결과를 `not_evaluated`(사유 포함)로 기록하면 현재 판정 코드가 이미 완전 재현을 막는다: `web_reproduction_status`는 `not_evaluated`가 하나라도 있으면 `reproduced`를 반환하지 않고 `partially_reproduced`로 떨어진다(`src/replica_mvp/web_demo.py:908-918`). 분모 보존은 기존 결과 집계가 기대 결과 전체를 세므로 유지된다.
- **I8 — 합의.** 수집 대체 순서를 실패 원인별로 고르는 Codex 보완을 수용.
- **I9 — 합의.** 최대 2회, 자동 `our_condition` 전환 금지.
- **I7 — 합의.** 변이 시험은 회귀 검사이며 실제 오류율 추정이 아니다. 변이 390건 전체는 회사별 실행 비용이 아니라 검증기 개발 시 1회 비용이지만, 첫 단계는 v4 관측 유형 위주의 작은 묶음으로 시작하는 데 동의.
