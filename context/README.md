# 공유 컨텍스트 운영

- `project-direction.md`: 프로젝트 목표·확정된 방향·미결정 사항의 기준 문서. Codex와 Claude가 작업 시작 시 읽는다.
- `active.md`: 진행 중인 토론과 링크. 토론 도우미가 관리한다.
- `tasks/<주제>-<고유ID>/`: 여러 세션에서 이어가는 토론. 단순 질문·수정에는 만들지 않는다.

## 토론을 요청할 때

“이 주제를 Claude랑 토론해”, “Codex랑 서로 리뷰해”, “이전 토론 이어서 해”라고 요청하면 `agent-debate` 스킬을 사용한다.
로컬 설치 경로는 Codex `~/.codex/skills/agent-debate/SKILL.md`, Claude `~/.claude/skills/agent-debate/SKILL.md`다. 두 경로는 같은 스킬을 가리킨다.

토론을 시작한 채팅이 진행을 맡고, 작업마다 Codex와 Claude의 새 전용 세션을 하나씩 만든다. 제안과 검토는 두 세션을 번갈아 호출한다. 작업의 brief와 현재 상태를 먼저 읽고, 제안·리뷰·수정은 작성자별 번호 파일로 남긴다. 상대 지적마다 수용·기각·보류와 근거를 적고, 진행자가 status를 짧게 갱신한다. 이전 의견은 덮어쓰지 않는다.

작업마다 상대 전용 세션을 생성하고 같은 작업에서는 정확한 세션 ID로만 재개한다. `session.json`과 `.runtime/`은 이 컴퓨터의 실행 상태로 Git에서 제외된다. 같은 제목도 새 작업이면 다른 ID를 받는다. 다른 체크아웃이나 PC에서 기존 실행 상태를 그대로 재사용하지 않는다.

중요한 쟁점 해결과 수정안 검토가 끝나면 결론을 남긴다. 사용자 결정이 필요하거나 근거 없이 반복되면 이견을 기록해 보고한다. 완료한 토론은 활성 목록에서 제외하며 기록은 보존한다. 모델 간 합의를 사용자 승인으로 취급하지 않고, 토론만 요청받았으면 제품 코드·배포·확정 방향은 변경하지 않는다.

세부 호출·오류 복구·종료 절차는 설치된 `agent-debate` 스킬을 따른다.
